# 🍋 Little Lemon - Restaurant Website (HTML & CSS)

## 📌 Overview

Simple restaurant website built using **pure HTML & CSS** as a frontend practice project.

The goal here was straightforward:

* Practice real page structure
* Build forms, layout, and UI elements manually
* Understand how a full static page comes together

No frameworks. No JavaScript logic (except a tiny alert). Just fundamentals.

---

## 🧩 Features

* 🧭 Navigation bar + header
* 🔍 Search bar UI
* 🖼️ Restaurant logo & branding
* 📖 Story section (collapsible)
* 🍽️ Menu section
* 🔗 Social media links
* ⭐ Rate button (basic interaction)
* ✅ User preferences (checkboxes)
* 💬 Comment input
* 📁 File upload input
* 📝 Sign-up form
* 📅 Table booking form
* 📍 Branches section with hover effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* No libraries or frameworks

## 🚀 How to Run

1. Download or clone the repo
2. Open `index.html` in your browser

That’s it. No setup, no dependencies.

---

## 🎯 What This Project Shows

* Semantic HTML structure
* Form handling (UI only)
* Layout using Flexbox + floats
* Styling with custom CSS
* Hover effects and transitions
* Basic responsiveness

---

## ⚠️ Issues / Limitations

Straight talk:

* ❌ No real backend (forms don’t actually submit)
* ❌ Search bar is UI only
* ❌ Some meta tags have typos (`property` written wrong)
* ❌ Image path for search icon is local (won’t work online)
* ❌ No validation logic (password match, email format, etc.)
* ❌ Accessibility is basic

---

## 💡 Possible Improvements

If you want to level this up:

* Add JavaScript (form validation + interactivity)
* Connect to backend (Node.js / Firebase)
